### Argentum — Agentic-First Language Model

[Argentum](https://github.com/danevndotcom/argentum) is an open-source, MIT-licensed research project exploring an execution-first architecture for language models.

Instead of focusing primarily on conversational responses, Argentum is designed around an autonomous task-completion loop:

```text
Observe → Reason → Plan → Act → Verify → Recover
```

The central research question is whether smaller, purpose-built models can outperform general-purpose frontier models specifically on autonomous execution tasks.

Current work includes:

- Building the training dataset
- Developing the first fine-tuned model
- Creating an agentic evaluation benchmark
- Publishing the architecture, research thesis, and roadmap openly
